# Cómo colaborar

¡Gracias por querer sumar a Manada Abierta!

## Antes de empezar
1. Abrí un issue explicando el problema o la mejora.
2. Para cambios grandes, conversá primero sobre el enfoque.
3. No subas datos personales, teléfonos, direcciones particulares, historias clínicas ni fotos de animales/personas sin permiso.
4. No inventes animales disponibles, campañas, presupuestos ni resultados.
5. Mantené el lenguaje respetuoso y no publiques listas negras ni acusaciones sin verificar.

## Primeros aportes
- Mejorar navegación por teclado y contraste.
- Añadir tests para filtros y formulario de demo.
- Diseñar cómo verificar la identidad de refugios y responsables.
- Proponer un esquema de datos sin incluir información real.
- Redactar guías que luego puedan revisar profesionales.

## Flujo sugerido
- Fork del repositorio.
- Crear una rama descriptiva: `feat/filtro-provincia` o `docs/guia-adopcion`.
- Hacer cambios pequeños y claros.
- Probar en móvil y escritorio.
- Abrir un pull request describiendo qué cambia, cómo probarlo y cualquier riesgo.

## Principio de seguridad
No automatizar decisiones críticas de adopción, riesgo de mordedura o tratamiento veterinario. Las herramientas pueden organizar información, pero las decisiones que afectan seguridad y bienestar necesitan revisión humana competente.
