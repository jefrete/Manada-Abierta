# 🐾 Manada Abierta

> **No necesitás ser senior para hacer algo que importe.**  
> Aprendé, probá, equivocáte, compartí lo que descubrís y ayudá a construir tecnología para el bienestar animal.

**Manada Abierta es un proyecto comunitario y open source** para conectar adopciones responsables, ayuda veterinaria, colaboración entre refugios y convivencia segura entre animales y personas. Queremos que sea un espacio donde desarrolladores con experiencia y personas que recién empiezan puedan aprender en un proyecto real, útil y construido entre todos.

**¿Estás aprendiendo HTML, CSS, JavaScript, diseño, testing o documentación? Podés participar.** No hace falta saberlo todo ni tener años de experiencia. Podés empezar arreglando un detalle visual, mejorando una explicación, probando la web en tu celular o proponiendo una idea.

[Explorar el código](./index.html) · [Cómo colaborar](./CONTRIBUTING.md) · [Reportar un problema](../../issues/new/choose)

## 🌱 Una forma simple de empezar

Si estás aprendiendo desarrollo, este proyecto puede ser tu espacio para practicar con otras personas:

- 🐾 **Elegí una tarea pequeña.** Mejorar un botón, revisar un texto, corregir un detalle móvil o escribir una guía ya suma.
- 🧪 **Experimentá sin miedo.** Usá una rama propia para probar una idea sin romper la versión estable.
- 🤝 **Pedí ayuda y ayudá a otros.** Las preguntas respetuosas son bienvenidas; nadie nace sabiendo Git.
- 🌿 **Aprendé con el proceso real.** Issues, ramas, commits, revisiones y *pull requests* forman parte del trabajo colaborativo.
- 💚 **Construí algo con propósito.** La tecnología es el medio; mejorar el bienestar animal es el objetivo.

No hace falta que tu primera contribución sea código. Una buena idea, una prueba bien documentada o una mejora de accesibilidad también pueden cambiar el proyecto.

## 🌳 Nuestro mapa de ramas

Queremos que las ramas tengan nombres propios y que el flujo de trabajo sea fácil de entender. Git permite usar estos nombres personalizados; **los nombres son una convención de la comunidad, no funciones especiales de GitHub**.

### Ramas permanentes

| Rama | Función |
|---|---|
| `manada` | Rama predeterminada y versión estable del proyecto. Los cambios llegan mediante *pull requests* revisados. |
| `laboratorio` | Integración de cambios que ya están listos para probarse en conjunto antes de publicarlos. |
| `vivero` | Ideas tempranas, prototipos y experimentos que todavía están verdes. |

Estas ramas son una propuesta de organización. No es necesario crearlas todas desde el primer día: podemos activar el flujo gradualmente a medida que haya colaboradores.

### Ramas de trabajo

Cada colaborador puede crear una rama para su tarea y abrir un *pull request* cuando esté lista para revisión.

| Prefijo | Uso | Ejemplo |
|---|---|---|
| `huella/` | Funcionalidades nuevas | `huella/perfiles-adopcion` |
| `rescate/` | Correcciones importantes | `rescate/error-formulario` |
| `patitas/` | Mejoras pequeñas | `patitas/ajustar-botones` |
| `refugio/` | Herramientas para refugios | `refugio/panel-animales` |
| `transparencia/` | Reportes y rendición de campañas | `transparencia/reportes` |
| `accesibilidad/` | Accesibilidad e inclusión | `accesibilidad/lectores-pantalla` |
| `experimento/` | Pruebas libres | `experimento/mapa-refugios` |
| `documentacion/` | Guías y documentación | `documentacion/como-colaborar` |

**Regla principal:** no trabajamos directamente sobre `manada`. Proponemos los cambios con *pull requests* para poder revisarlos, conversar y aprender en equipo. Si recién estás empezando, podés abrir uno aunque necesite ajustes: la revisión es parte del aprendizaje.

## 🐕 ¿Qué queremos construir?

Una plataforma abierta para facilitar la colaboración en torno al bienestar animal:

- **Adopciones responsables:** perfiles claros y dignos para animales que buscan hogar.
- **Ayuda veterinaria:** información organizada para iniciativas de asistencia, con responsables y criterios verificables.
- **Campañas transparentes:** objetivos, presupuestos, avances y rendiciones públicas cuando exista una implementación real.
- **Herramientas para refugios y rescatistas:** formas sencillas de organizar información y coordinar esfuerzos.
- **Accesibilidad y cuidados:** experiencias utilizables desde distintos dispositivos y por personas con diferentes necesidades.
- **Convivencia segura:** información responsable para proteger a animales y personas, sin fomentar el maltrato ni las acusaciones sin verificar.

La plataforma está en una etapa inicial. Estas son metas, no funcionalidades que ya estén operativas.

## 💻 ¿Qué hay en este repositorio?

- `index.html`: prototipo adaptable a distintos tamaños de pantalla, con HTML, CSS y JavaScript en un solo archivo.
- Perfiles de animales ficticios con filtros de demostración.
- Secciones de ayuda, campañas de ejemplo, convivencia responsable y participación.
- Un formulario demostrativo que solo muestra un mensaje en pantalla.
- `CONTRIBUTING.md`: guía para proponer cambios y colaborar.
- `CODE_OF_CONDUCT.md`: pautas para participar con respeto.
- `SECURITY.md`: cómo comunicar posibles problemas de seguridad.
- `LICENSE`: licencia MIT para el código del proyecto.

### Probar la web

1. Descargá o cloná el repositorio.
2. Abrí `index.html` en tu navegador.
3. Explorá la página y probala también en un celular.
4. Si encontrás un problema o una mejora, abrí un *issue* para conversarlo.

La versión actual no requiere instalación ni dependencias externas.

> **Importante:** este repositorio contiene un prototipo. Los animales y las campañas mostrados son ficticios. La web no procesa adopciones reales, no recibe donaciones y no envía ni almacena los datos del formulario. No cargues información personal ni datos reales de animales en esta demo.

## 🤝 Cómo colaborar

1. Revisá los [issues abiertos](../../issues) o proponé una idea nueva.
2. Comentá qué te gustaría hacer para evitar duplicar trabajo.
3. Creá una rama para tu tarea, siguiendo las convenciones de nombres de arriba.
4. Hacé cambios pequeños y explicá qué resuelven.
5. Abrí un *pull request* hacia la rama de integración que se indique en la tarea.
6. Conversá sobre las sugerencias y ajustá el cambio si hace falta.

Antes de colaborar, leé [CONTRIBUTING.md](./CONTRIBUTING.md), [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) y [SECURITY.md](./SECURITY.md).

### Ideas para tus primeras contribuciones

- Revisar la experiencia en pantallas pequeñas.
- Mejorar contraste, navegación por teclado y textos alternativos.
- Corregir errores de escritura o explicar mejor una sección.
- Proponer perfiles de demostración más accesibles y respetuosos.
- Escribir pruebas manuales para los filtros y el formulario de ejemplo.
- Diseñar un modelo de datos para animales, refugios y solicitudes, sin publicar datos reales.
- Investigar buenas prácticas de adopción responsable con fuentes fiables.
- Documentar cómo ejecutar, probar o mejorar el proyecto.

Si todavía no sabés qué elegir, abrí un *issue* y contanos qué estás aprendiendo. Podemos buscar una tarea adecuada a tu nivel.

## 🧭 Principios del proyecto

- **Código abierto:** compartimos el código y facilitamos que otras personas aprendan y contribuyan.
- **Bienestar animal:** las decisiones deben priorizar la seguridad y las necesidades de cada animal.
- **Transparencia:** cualquier campaña real futura deberá tener responsables identificados, objetivos claros y rendición verificable.
- **Privacidad:** no publicar datos sensibles, domicilios particulares ni información personal sin autorización.
- **Respeto:** no toleramos acoso, discriminación ni humillaciones por el nivel de experiencia.
- **Colaboración:** la idea no es que todo dependa de una sola persona; buscamos construir una comunidad capaz de continuar el trabajo.
- **Responsabilidad:** las decisiones veterinarias deben quedar en manos de profesionales; las herramientas digitales no sustituyen su criterio.
