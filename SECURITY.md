# Seguridad y privacidad

Esta versión es un prototipo estático: no tiene backend, autenticación, base de datos, pagos ni envío de formularios. El formulario de participación muestra solamente un mensaje local y no almacena datos.

## Para reportar un problema
Abrí un issue sin incluir datos personales ni detalles que expongan a una persona o animal. Para vulnerabilidades sensibles, contactá en privado a los mantenedores cuando el proyecto tenga un canal oficial publicado.

## Antes de usar datos reales
- Implementar controles de acceso y minimización de datos.
- Obtener consentimiento para publicar fotos e historias.
- Evitar publicar domicilios exactos, datos de menores o información veterinaria sensible.
- Diseñar moderación, retención y eliminación de datos.
- No recibir donaciones hasta contar con responsables, registros contables, mecanismos de pago seguros y rendición verificable.
- No publicar denuncias identificables sin un proceso adecuado de revisión.

No uses esta demo para emergencias. Ante un riesgo inmediato, contactá los servicios locales competentes.
